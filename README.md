# Portfolio
Here is a complete, production-ready, fully responsive multilingual my portfolio landing page. It implements semantic HTML5, modern CSS (Grid, Flexbox, Custom Properties), and clean, vanilla JavaScript to handle both the Light/Dark mode toggle and the dynamic client-side translation system across English, Finnish, and Russian.

To support rich UI elements and visual flair, this architecture includes FontAwesome 6 for crisp vector icons and uses optimized text layouts designed to handle varying string lengths across different languages without breaking.
